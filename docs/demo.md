# Demo script

1. Open Dashboard and note the active-driver, safety, incident, and trip metrics.
2. Open Route Planner; keep Cape Town CBD → Cape Town International Airport and choose Find routes.
3. Compare the three alternatives, select each card, and inspect its highlighted path and factor explanation.
4. Select Balanced Route and start the simulated trip.
5. Advance automatically, then choose Simulate accident or Simulate crime.
6. Observe the score drop, warning, audit entry, and safer reroute recommendation.
7. Accept the safer route; return to Dashboard to see the fleet warning state.
8. Open Incidents and confirm/dispute the new report; observe confidence change.
9. Return to Live Trips, end the trip, and review the audit history.
10. In Expo, show the home safety status, simulated trip, report form, and press-and-hold MVP SOS.
