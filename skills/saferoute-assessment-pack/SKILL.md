# SafeRoute assessment pack

Collect evidence already supported by source, Git, tests, workflows, and the deployed application.

## Workflow

1. Read `docs/assessment-marking-guide.md` and the assignment rubric supplied by the learner.
2. Run `scripts/collect-evidence.ps1` from the repository root.
3. Link claims to files, tests, commits, pull requests, workflows, or screenshots.
4. Mark student details, contact attempts, personal learning, manual acceptance results, and assessor actions as learner-owned placeholders.
5. Keep screenshots of actual software separate from generated presentation artwork.
6. Record failed tests and limitations honestly.
7. Finish with a checklist of missing personal evidence.

## Integrity rules

Never invent contacts, invitations, screenshots, test runs, lessons learned, dates, assessor approval, or production capabilities. Generated imagery may support a presentation but is not proof that software works.
